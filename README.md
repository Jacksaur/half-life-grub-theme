### 🛠️ Installation

```bash
git clone https://github.com/kingkusuo/half-life-grub-theme
cd half-life-grub-theme
chmod +x install.sh
sudo ./install.sh
```

Consider giving a ⭐ if you liked it

This theme works best for 1920x1080 displays.
